# Contributing

This is a community recipe for building a portable FT8/WSJT-X station on a
Raspberry Pi — not a supported product. It grew out of one person's actual
field setup, generalized so others can adapt it.

- Found something wrong, outdated, or unclear? Open an issue or PR.
- Got a variant that works better (different Pi model, different rig
  interface, different Wi-Fi setup)? PRs adding alternatives/notes are
  welcome — please keep additions general enough for others to adapt,
  not tied to one specific personal setup.
- No promises on response time — this is maintained on a best-effort basis.
